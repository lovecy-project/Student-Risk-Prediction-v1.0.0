# StudyBalance AI

A frontend-only student wellness website that estimates academic burnout risk using a transparent rule-based scoring model.

## Features

- Responsive premium SaaS-style user interface
- Multi-step burnout assessment
- Explainable burnout scoring engine
- Results with recommendations and chart visuals
- Local storage dashboard and history
- Weekly study planner with edit/delete support
- Dark/light theme toggle
- Download/print report support

## Run locally

1. Open the project folder in VS Code.
2. Install the Live Server extension from the Extensions panel.
3. Right-click `index.html` and choose **Open with Live Server**.
4. The site should open in a browser and run locally without any backend dependencies.

## Important notes

- Data is stored in the user's browser using `localStorage`.
- This app is educational and not a medical diagnostic tool.
- The scoring thresholds and weights are intentionally transparent and adjustable.
